## 6️⃣ Настройка расписания

### Вариант A: Windows Task Scheduler

1. Откройте **Task Scheduler**
2. **Create Basic Task** → "ETL Pipeline 3 days"
3. **Trigger**: Daily → Repeat task every: 10 minutes
4. **Action**: Start a program
   - Program: `python.exe`
   - Arguments: `pipeline_3days.py 3`
   - Start in: `c:\Users\A.Gorbatenko\Documents\Dashboard\Скрипты операций и суммы сделки`
5. **Settings**: 
   - ✅ "If the task is still running when the next trigger fires, do not start a new instance"

### Вариант B: Linux systemd

Создайте файлы:

**`/etc/systemd/system/etl-3days.service`**:
```ini
[Unit]
Description=ETL Pipeline 3 days
After=network.target

[Service]
Type=oneshot
User=admin1
WorkingDirectory=/home/admin1/script
ExecStart=/usr/bin/python3 /home/admin1/script/pipeline_3days.py 3
StandardOutput=journal
StandardError=journal
```

**`/etc/systemd/system/etl-3days.timer`**:
```ini
[Unit]
Description=Run ETL every 10 minutes

[Timer]
OnBootSec=1min
OnUnitActiveSec=10min
Persistent=true

[Install]
WantedBy=timers.target
```

**Активация:**
```bash
sudo systemctl daemon-reload
sudo systemctl enable etl-3days.timer
sudo systemctl start etl-3days.timer
sudo systemctl status etl-3days.timer
```

### Вариант C: Cron (Linux)

```bash
crontab -e

# Каждые 10 минут
*/10 * * * * cd /home/admin1/script && python3 pipeline_3days.py 3 >> logs/cron.log 2>&1

# Ежедневно в 23:59 (7-дневный пайплайн)
59 23 * * * cd /home/admin1/script && python3 pipeline_3days.py 7 >> logs/cron_7days.log 2>&1
```

## 7️⃣ Мониторинг

### Просмотр логов
```bash
# Последние логи
tail -f logs/pipeline_3days_*.log

# Все логи за сегодня
cat logs/pipeline_3days_$(date +%Y%m%d)*.log
```

### Проверка в SQL Server
```sql
-- Последние запуски
SELECT TOP 10 * FROM raw_.etl_log ORDER BY created_date DESC;

-- Актуальность данных
SELECT 
    'fact_operation' AS table_name, 
    MAX(date_key) AS last_date, 
    COUNT(*) AS row_count 
FROM dwh.fact_operation
UNION ALL
SELECT 'fact_penalty', MAX(date_key), COUNT(*) FROM dwh.fact_penalty
UNION ALL
SELECT 'fact_location_snapshot', MAX(date_key), COUNT(*) FROM dwh.fact_location_snapshot;
```

## 8️⃣ Решение проблем

### ❌ Ошибка: "Таблица не найдена"
```
❌ Таблица dwh.fact_operation не найдена
```
**Решение:** Запустить `Full.sql` для создания таблиц.

### ❌ Ошибка: "Timeout expired"
```
❌ ШАГ 1 превысил таймаут (30 минут)
```
**Решение:**
- Увеличить таймаут в `pipeline_3days.py` (строка `timeout=1800`)
- Проверить скорость сети
- Добавить индексы в исходные таблицы

### ❌ Ошибка: "Login failed"
```
❌ Ошибка подключения к базе данных
```
**Решение:** Проверить логин/пароль в начале каждого скрипта.

### ❌ Пайплайн выполняется слишком долго
**Решение:**
1. Проверить логи на предмет медленных запросов
2. Добавить индексы в `raw_.` таблицы
3. Увеличить интервал запуска (например, каждые 15 минут вместо 10)

## ⚠️ Важные замечания

### 1. Надёжность
- **Единый вызов `executemany()`** — SQL Server сам оптимизирует вставку
- При ошибке — транзакция откатывается (данные не повредятся)
- 150,000 строк — **небольшая нагрузка** для SQL Server (память ~50-100 MB)

### 2. Почему это работает
- `executemany()` отправляет **все данные за один сетевой вызов**
- SQL Server вставляет данные **внутренними оптимизированными методами**
- Никаких накладных расходов на циклы в Python

### 3. Ресурсы
- **Память:** ~50-100 MB на таблицу (не критично)
- **Сеть:** ~5-10 MB данных (один пакет)
- **CPU:** Загрузка на 10-20% во время вставки

### 3. Логи
Теперь в логах видно:
- Скорость вставки (строк/сек)
- Время по каждой таблице
- Общее время пайплайна
